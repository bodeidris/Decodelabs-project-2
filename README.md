DecodeLabs Project 2 – Exploratory Data Analysis (Excel)

Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) using Microsoft Excel to understand patterns, trends, distributions, and calculate key statistics mean,median and count within the dataset.
Identify trends and outliers

The goal was to summarize the data through descriptive statistics and identify meaningful insights that can support better business decision-making.

This project was completed as part of my DecodeLabs Data Analytics Internship.

Project Objectives

* Analyze the dataset using descriptive statistics.
* Calculate key statistical measures [mean,median,count].
* Identify trends and outliers.
* Summarize important business insights.
* Strengthen Excel data analysis skills.

Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Functions (MEAN, MEDIAN, COUNT)
* Sorting and Filtering

Analysis Performed

The following analyses were carried out:

* Calculated the Mean (Average).
* Calculated the Median.
* Counted the total number of records.
* Examined the distribution of the data.
* Identified trends within the dataset.
* Investigated possible outliers.
* Summarized key findings using descriptive statistics.

 Key Insights

Some of the insights obtained include:

* The mean and median were compared to understand the distribution of the data.
* Trends were identified by examining the frequency and values across the dataset.
* Potential outliers were observed where values differed significantly from the majority.
* The analysis provided a clearer understanding of customer transactions and business performance.
